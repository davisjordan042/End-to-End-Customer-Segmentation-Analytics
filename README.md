# End-to-End-Customer-Segmentation-Analytics
This project was managed using Agile principles (Scrum) and documented retrospectively in Jira to reflect a real-world analytics delivery process. 
Although the analytics work was already completed, Jira was used to backfill epics, stories, and workflow states to demonstrate structured project execution, and traceability, mirroring how analytics projects are managed in professional environments.

# Epic
This epic represents the full lifecycle of transforming raw customer data into actionable business insights.

# Stories (Backfilled)
The following Jira stories were created to document completed work:

## Story	Description
- Data Ingestion: Loaded transactional and customer data into PostgreSQL
- Data Cleaning: Validated customer records and handled missing/inconsistent values
- RFM Feature Engineering:	Computed Recency, Frequency, and Monetary metrics
- Customer Clustering: Segmented customers using clustering techniques
- Segment Interpretation:	Translated clusters into business-friendly segments
- Data Exposure:	Created structured datasets / views for consumption
- Insights Generation:	Identified revenue and retention patterns
- Documentation:	Produced architecture diagrams and analytical documentation

# Status Tracking
All stories followed a standard Jira workflow:
To Do → In Progress → Review → Done
Most tickets were ultimately marked Done, reflecting completed analytical work and reinforcing delivery accountability.
